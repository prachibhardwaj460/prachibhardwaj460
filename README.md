`HTML5` • `CSS3` • `JavaScript (ES6+)` • `LocalStorage API` • `Chart.js`

### ☕ [GrabNGo](https://github.com/prachibhardwaj460/GrabNGo)
**Campus Food Pre-Ordering & Queue Management System**

A modern web application built for campus cafeterias to eliminate dining queues, enable seamless mobile meal pre-ordering, and provide real-time kitchen display workflows for food vendors.

<p>
  <a href="https://github.com/prachibhardwaj460/GrabNGo">
    <img src="https://img.shields.io/badge/Status-Phase%201%20Architecture-FFB6C1?style=for-the-badge&logo=react&labelColor=87CEEB" alt="GrabNGo Status" />
  </a>
</p>

**Tech Stack**:
`React 18` • `TypeScript` • `Vite` • `Modern CSS3` • `React Router v6`

**Key Highlights**:
- 📱 **Student Flow**: Browse cafeteria menus, stage customizable carts, and monitor real-time queue position.
- 👨‍🍳 **Vendor KDS Portal**: Kitchen Display System with instant order acceptance, queue alerts, and live item stock toggles.
- ⏱️ **Queue Elimination**: Lifecycle order tracker: *Received ➔ Preparing ➔ Ready for Pickup*.
- 🎨 **Café Aesthetic Design**: Custom CSS tokens with clean typography, soft contrast, and zero layout shift.

<details>
<summary><b>🔍 Expand GrabNGo Development Roadmap</b></summary>
<br/>

- **Decoupled Architecture**: 10-phase roadmap ensuring strict frontend type safety before backend integration.
- **Strict TypeScript**: Full end-to-end type definitions for orders, vendor menus, and auth states.
- **Future Backend**: Node.js + Express + Prisma ORM + SQLite database.
- **Repository**: [Explore GrabNGo Source Code ➔](https://github.com/prachibhardwaj460/GrabNGo)

</details>
